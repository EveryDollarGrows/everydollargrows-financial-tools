# EveryDollarGrows Financial Tools

Free financial education tools from [EveryDollarGrows](https://everydollargrows.com/).

## Savings Goal Calculator

An original, browser-based savings calculator. Enter a target, current savings, monthly contribution, and annual interest assumption to estimate the number of months to reach a goal.

**Live demo:** After enabling GitHub Pages, visit https://everydollargrows.github.io/everydollargrows-financial-tools/

**Continue planning:** [Free Savings Goal Planner](https://everydollargrows.com/free-savings-goal-planner/) · [Financial Calculators & Tools](https://everydollargrows.com/personal-finance-calculators-and-tools/)

## Calculation

Each month, the balance is multiplied by `1 + annualRate / 1200`, then the monthly contribution is added. The tool simulates up to 1,200 months. Results are illustrative, not investment advice; rates can change, and taxes and fees are excluded.

## Development

The project uses plain HTML, CSS, and JavaScript with no dependencies. Open `index.html` locally to test.
